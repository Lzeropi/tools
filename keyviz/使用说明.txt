keyviz 按键可视化工具使用说明
==============================

位置：/opt/myplugins/tools/keyviz/keyviz.py
用途：KDE Plasma Wayland 下实时显示键盘按键与鼠标操作的浮窗工具，
     适合录屏教学、快捷键演示。按下即显示、全部松开后保持 2.5 秒再淡出。

----------------------------------------
一、什么时候用
----------------------------------------
录制教学视频、给别人演示快捷键操作时，屏幕底部会实时浮现按键组合，
观看者能清楚看到你按了什么。

Wayland 下的特点：本工具直读内核输入设备（evdev），不依赖 X11，
在 KDE Plasma Wayland 会话下原生应用按键也能捕获
（screenkey 等传统工具在 Wayland 下抓不到，只能录到 XWayland 应用）。

----------------------------------------
二、怎么用
----------------------------------------
启动（二选一）：

    sudo python3 ~/.local/bin/keyviz.py

    sudo python3 /opt/myplugins/tools/keyviz/keyviz.py

带鼠标指示启动（推荐教学时用）：

    sudo python3 ~/.local/bin/keyviz.py --mouse

说明：
- ~/.local/bin/keyviz.py 是指向 /opt/myplugins/tools/keyviz/keyviz.py
  的软链接，两种写法等价。
- 结束工具：Ctrl+C（终端前台运行）；或另开终端 pkill -f keyviz.py

免 sudo 启动（可选，一次性配置）：

    sudo usermod -aG input $USER
    然后注销重新登录生效。之后直接
    python3 ~/.local/bin/keyviz.py --mouse
    不再需要 sudo。

----------------------------------------
三、显示效果
----------------------------------------
- 位置：屏幕底部居中，距底边 56px
- 键帽样式：深色衬底容器 + 三种键帽
  · 修饰键（Ctrl/Alt/Super/Shift）：深色键帽白字，固定排序 Ctrl→Alt→Super→Shift
  · 普通按键：浅色键帽深字，标点显示真实字符（. , / ; ' - = 等）
  · 鼠标：自绘图标键帽（左键/右键按下半边绿色高亮，中键滚轮点绿色，
    侧键左缘小块，滚动时上下箭头）
- 组合行为（keyviz 语义）：
  · 按下即显示，按住的修饰键与普通键实时组合
  · 松开某键后已显示的组合保持不变（不缩回去）
  · 全部松开后整条组合冻结保持 2.5 秒，然后 0.3 秒渐隐消失

----------------------------------------
四、依赖
----------------------------------------
Arch Linux 安装：

    sudo pacman -S python-evdev python-pyqt5

（其余 Linux 发行版对应 evdev、PyQt5 两个 Python 包即可。）

----------------------------------------
五、常见问题
----------------------------------------
Q: 提示"未找到键盘设备"？
A: 读取 /dev/input 需要权限，加 sudo 运行；或按上面方法把用户
   加入 input 组。

Q: 浮窗挡住了演示内容？
A: 调整脚本头部可调参数：BOTTOM_MARGIN（距底边距离）、HOLD_MS
   （保持时长）、FONT_SIZE（字号）、FADE_MS（淡出时长）。

Q: 为什么不用 screenkey？
A: screenkey 基于 X11 的 XRecord，在 Wayland 会话下只能捕获
   XWayland 应用，原生应用按键不可见。本工具走 evdev 层，
   与显示服务器无关。

Q: 想改键帽配色？
A: 脚本头部 CAP_STYLE 字典集中定义了三种键帽样式，改
   background/color 即可。
